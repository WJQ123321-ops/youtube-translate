# AI 翻译指南 — SRT 字幕翻译规范

本指南供 Agent 执行「英文 SRT → 中文 SRT + 双语 SRT」翻译步骤时参考。

---

## SRT 格式速查

```
1
00:00:01,500 --> 00:00:04,200
Hello, and welcome to this video.

2
00:00:04,200 --> 00:00:07,800
Today we'll talk about machine learning.
```

每条字幕由四部分组成：
1. **序号**（整数，从 1 开始）
2. **时间轴** `HH:MM:SS,mmm --> HH:MM:SS,mmm`（逗号是毫秒分隔符）
3. **文本**（可多行）
4. **空行**（条目之间）

---

## 翻译工作流

### 1. 读取英文 SRT

使用 `srt_utils.py parse` 解析，或直接读取文件内容。

### 2. 批量翻译

**关键原则：通读全文再翻译。** 字幕是连续的口语，前后文紧密关联。
不要逐条孤立翻译，而应：
- 先通读所有字幕条目，理解整体内容
- 再逐条翻译，保持术语和语气一致

### 3. 翻译质量要求

| 要求 | 说明 |
|------|------|
| **口语化** | 字幕是给观众快速阅读的，用简洁自然的口语，不用书面长句 |
| **长度控制** | 中文每行不超过 15-20 字（对标英文每行约 42 字符）。过长时断句 |
| **保留原意** | 不增删内容，不添加解释性文字（除非原文有隐含意思必须补全） |
| **术语一致** | 同一术语全文统一翻译 |
| **不翻译的内容** | 人名（可附中文译名）、品牌名、网址、代码、专有名词 |
| **标点** | 中文用中文标点（，。！？）。句末一般不加句号（字幕惯例） |
| **语气词** | 保留原文语气（感叹、疑问、停顿），适度转换语气词 |

### 4. 特殊情况处理

- **声音描述**：`[Music]`、`[Applause]`、`[Laughter]` 等保留英文方括号格式
- **数字单位**：注意中英文数字单位差异（如 million → 百万，billion → 十亿）
- **双关/文字游戏**：尽量找到中文对应，无法对应时直译并保持通顺
- **口误/重复**：可适当润色，去除无意义的重复（如 "I, I, I think" → "我认为"）

### 5. 输出文件

翻译完成后，生成两个文件：

#### 中文 SRT (`zh.srt`)
```
1
00:00:01,500 --> 00:00:04,200
你好，欢迎观看这个视频

2
00:00:04,200 --> 00:00:07,800
今天我们来聊聊机器学习
```

#### 双语 SRT (`bilingual.srt`)
```
1
00:00:01,500 --> 00:00:04,200
Hello, and welcome to this video.
你好，欢迎观看这个视频

2
00:00:04,200 --> 00:00:07,800
Today we'll talk about machine learning.
今天我们来聊聊机器学习
```

**双语 SRT 格式规则：**
- 英文在上，中文在下
- 两行之间不加空行（它们属于同一条字幕）
- 时间轴与英文 SRT 完全一致

### 6. 合并双语 SRT

可以使用脚本自动合并：

```bash
python "$SKILL_PATH/scripts/srt_utils.py" bilingual en.srt zh.srt bilingual.srt
```

或直接在生成中文 SRT 时，同时生成双语 SRT（推荐，更高效）。

## 翻译示例

**原文：**
```
3
00:00:07,800 --> 00:00:11,200
So, the first thing you need to know is that
neural networks are basically function approximators.

4
00:00:11,200 --> 00:00:14,500
They take some input, and they produce some output,
and they learn from examples.
```

**中文翻译：**
```
3
00:00:07,800 --> 00:00:11,200
首先你需要知道的是
神经网络本质上是函数逼近器

4
00:00:11,200 --> 00:00:14,500
它们接收输入，产生输出
并且从示例中学习
```

**注意：** 原文是多行文本，翻译后也保持多行，每行长度适中。
